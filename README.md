# gestión-servicios-web-ts

Sistema de gestión para talleres de servicio técnico.

**Stack:** Next.js 16 · TypeScript · MySQL 8.4 · Prisma · Tailwind 4 · Shadcn UI

---

## 🚀 Arranque rápido

```powershell
pnpm install
pnpm db:up         # Levanta MySQL en Docker
pnpm db:seed       # Carga datos de prueba
pnpm dev           # http://localhost:3000
```
